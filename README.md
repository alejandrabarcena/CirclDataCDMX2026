# CirclData CDMX

Sistema inteligente de gestión de residuos para eventos masivos y recintos de gran capacidad.

## Descripción

CirclData CDMX es una propuesta de plataforma digital orientada a la economía circular y la gestión inteligente de residuos durante eventos masivos como conciertos, festivales y partidos de fútbol.

El proyecto combina visualización de datos, simulación de generación de residuos, análisis de sostenibilidad y herramientas de apoyo para la toma de decisiones mediante inteligencia artificial.

## Problema

Los eventos masivos generan grandes volúmenes de residuos y presentan desafíos operativos relacionados con:

* Distribución eficiente de contenedores
* Predicción de residuos generados
* Monitoreo de puntos críticos
* Optimización logística
* Indicadores de sostenibilidad

## Solución

La plataforma permite:

* Seleccionar recintos y escenarios de operación
* Simular parámetros de eventos
* Estimar generación de residuos
* Visualizar mapas de calor
* Optimizar la ubicación de contenedores
* Generar reportes de sostenibilidad
* Evaluar indicadores ambientales
